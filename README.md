# Эксперимент 1

Предположение: четыре массива по 8_000_000 элементов байт займут на каждом шаге 8_000_000 байт, 16_000_000 байт, 24_000_000 байт, 32_000_000 байт соответственно.

Шаг 0: 2.7 МБ
Шаг 1: 10.4 МБ
Шаг 2: 18.2 МБ
Шаг 3: 25.8 МБ

1. С каждым шагом потребление памяти растёт.
2. Рабочий набор увеличивается.
3. На Шаге 0 массивы ещё не заданы, а использование памяти есть, потому что она идёт на нужды самой программы. Возможно, хранение других переменных и тп.
4. Объём элементов это то, сколько памяти занимают сохранённые массивы, а рабочий набор это сколько занимает программа вообще.

5. Нам удобнее смотреть потребление памяти Prac05, а не всего компьютера. Prac05 на фоне всей ОЗУ будет выглядеть погрешностью. Кроме массивов в памяти хранятся переменные, функции и тп от нашей программы, поэтому удобно отдельно смотреть за памятью, выделенной именно под массивы.

Шаг 1: 33.3 МБ
Шаг 2: 64.0 МБ
